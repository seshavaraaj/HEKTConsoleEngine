# Console Game Engine

A lightweight experimental game engine built in C/C++ using a terminal console character buffer for rendering.

## Features

- Console character buffer rendering
- Real-time terminal updates
- ASCII / Unicode rendering
- Simple game loop
- Input handling
- Lightweight architecture

## Goals

This project is focused on:

- Learning game engine architecture
- Exploring char buffer rendering
- Building retro-style console games

## Planned Features

- Collision detection
